# B-9 我需要這個 (I need this)

> 專案線上預覽：[https://sylvie0109.github.io/I-need-this/](https://sylvie0109.github.io/I-need-this/)

## 📝 專案介紹
此專案為 **六角學院 2025網頁切版直播班 | 夏季班** 之團隊專題作品。

>這是一個專注於「生活小物」與「特調香氣」的線上購物平台。

>希望提供一個能輕鬆提升生活品質的管道，讓使用者透過精選的香氛與小物，找到屬於自己的美好時光與療癒感。

>從自身對香氛、質感小物的喜愛出發，希望能將這份體驗分享給更多人，建立一個有溫度、有故事的電商品牌。

## ✨ 主要功能
* **響應式設計 (RWD)**：適應各種載具尺寸（手機、平板、電腦）。
* **首頁與導覽**：精選商品輪播與分類快速導覽。
* **商品列表與篩選**：（僅限介面切版呈現，暫無互動篩選功能）
* **商品細節頁**：詳細規格說明與數量增減。
* **購物車流程**：商品加入購物車並且確認數量規格。
